What "supported" means

Each layout is tested with statements built to the bank's published column format, using fictional data, and every test checks that each running balance reconciles. Banks change formats and offer several for different account types, so a statement from a listed bank can still be unreadable. If a file cannot be read, you see a clear message and you are not charged.

Banks that are not listed may work if they use a similar layout, but we do not support them yet. The statement must be a text PDF downloaded from the bank. Scanned images are not accepted.
